THE UNION POSTER — one framed play-sheet, three tones

A reconciliation pass on the Pilot / Mech / Crawler live-sheet shells. Direction: each sheet becomes a single printed-poster frame — an identity band with the user image seated at its leading edge, a vitals instrument block that condenses into the top bar on scroll, and every collection as Slab-headed compact entity rows. Entity cards themselves are canonical and untouched. Built exclusively from system primitives; dashed grey chips are deck annotations, not UI.

03Decisions & variations

The three contested regional calls, side by side. Schematics use the pilot accent; the rust outline marks the recommendation.

A · Image placement
Where the user image seats inside the identity band.
Recommended
Portrait-left (banner variant for wide art)
Image is a grid citizen: pilot gets a 3:4 portrait at the identity’s leading edge; mech/crawler stretch the same seat into a banner. Empty state is the same seat as a dropzone — the poster never reflows.
Identity-banner only
Great for mech/crawler art, but forces portraits into a letterboxed crop and pushes vitals below the fold on mobile.
Floating corner badge
Charming avatar energy, but it breaks the printed-poster alignment, collides with the top bar, and dies in print.
B · Vitals gauge
The instrument that carries HP / SP / EP / Heat.
Recommended
Segmented bar (today’s gauge)
HP7/10
Reads like the printed sheet’s tick-boxes; one tap = one point; scales from AP 5 to crawler SP 25; the heat redline falls out of it for free.
Pip-dial (grouped dots)
HP 7/10
Pretty at ≤10, but wraps into ragged rows past that, and round pips read “ammo”, not structure.
Ring / dial
7/10
Dashboard-slick but off-vocabulary: hides max, hard to tap per-point, and nothing in the printed sheets is circular.
C · Identity band composition
How the name and biography fields organize inside the identity card.
Ledger rows (label : value list)
Scannable and dense, but every field weighs the same — the callsign/pattern name never gets to be the hero.
Recommended
Hero name + stamp-label grid
Callsign / pattern name set big in the condensed face (as on the printed sheet); everything else in a stamp-labeled, ruled-line grid. The hero line is also the top-bar stamp’s source of truth.
Split card + stat band
Puts stat boxes inside a sub-header band DisplayCard-style — right for the mech’s chassis strip, but overkill for pilot/crawler prose fields.
Shell rules this direction commits to
  • One poster frame per sheet — top bar → identity band (with image seat) → vitals instrument block → Slab-headed collections → linked units. Same skeleton, three accents.
  • Image is a reserved grid seat, portrait-left for pilots and banner for mech/crawler; empty = EmptyState dropzone in the same seat; filled = 3px-ink framed art. The grid never reflows between states.
  • Vitals condense upward — the right-column gauges become the mini-vital chips in the condensed top bar on scroll; gauges are always live (tap a segment), never behind an edit mode.
  • Click-to-edit per container — one small rust ✎ per card/footer; collections keep an always-visible “+ Add” in their Slab; steppers appear only inside a container’s edit state.
  • Entity weight is sacred — only true game entities wear the 3px entity border; generic gear rows drop to 1.5px chrome; state (damaged/destroyed/over-cap) is a treatment, never a new hue.
  • Mobile is the same poster read top-to-bottom — single column, ≥44px targets, no horizontal scroll; the crawler’s storage rail re-seats as a stacked Storage section.
