# Cycle 3 — Crawler Builder (#191)

## What was built

A standalone crawler builder at `apps/in-the-union-now/src/routes/crawlers/new.tsx`,
backed by three focused components:

- **TechLevelSelector** — renders all 6 CrawlerTechLevel entries (from
  `SalvageUnionReference.CrawlerTechLevels`) as toggle buttons. Accepts a
  minimal `Pick<SURefMetaCrawlerTechLevel, 'id' | 'name' | 'techLevel'>` prop
  to avoid strict-type issues with the `schemaName` discriminant added by
  `LazyModel.all()`.

- **BaysEditor** — add/remove string slugs for bay assignments. Uses local
  `useState` for the in-progress input; calls `onChange` with the new array
  on each mutation.

- **SystemsList** — renders systems filtered by `techLevel <= selected TL`.
  Excludes Bio/Nanite (`'B'`/`'N'`) tech levels from the numeric comparison.

- **CrawlerBuilder** — orchestrates the three sub-components and the form
  submit flow. On submit, calls `useEntityStore.getState().create('crawler',
  { ... })`. The db layer injects `id`, `createdAt`, and `updatedAt`, so
  those are omitted from the call-site payload.

- **Route** — `createFileRoute('/crawlers/new')` navigates to `/` on success
  or cancel. `routeTree.gen.ts` was regenerated by running Vite from the app
  root with `node .../vite build /path/to/app` (the TanStack Router Vite
  plugin runs in `configResolved` and updates the file on startup).
